# БУНКЕР ОНЛАЙН — Веб-приложение настольной психологической игры

Полностью статическое адаптивное веб-приложение (Single Page Application) на **React + TypeScript + Vite + Tailwind CSS**, готовое к деплою на **GitHub Pages**, с синхронизацией в реальном времени через **Firebase** (Realtime Database или Cloud Firestore + локальный мульти-вкладочный режим из коробки) и генерацией художественного финала через **Google Gemini REST API**.

---

## Возможности

1. **Клиентская админ-панель и хранение секретов в `localStorage`:**
   - Защита мастер-паролем (задаётся при первом входе).
   - **Конфигуратор Firebase «на лету»:** принимает как строгий JSON, так и скопированный из консоли код `const firebaseConfig = { ... }`, проверяет соединение тестовой записью.
   - **Настройка Gemini API:** ввод ключа, выбор модели (`gemini-2.5-flash`, `gemini-2.0-flash`, `gemini-1.5-flash`) и проверка валидности ключа тестовым запросом.
   - **Конструктор и редактор паков:** создание, клонирование, редактирование, экспорт и импорт JSON-паков (сценарии катастроф, пресеты бункера, базы карт для всех 11 характеристик, обязательные спец. способности для «Профессии», «Хобби» и «Спец. возможности»).

2. **11 обязательных характеристик игрока и интерактивные способности (`ℹ️`):**
   - Каждому участнику генерируется уникальное досье из 11 категорий: *Профессия, Пол и возраст, Здоровье, Телосложение, Хобби, Человеческая черта, Фобия, Крупный инвентарь, Рюкзак, Дополнительное сведение, Спец. возможность*.
   - Возле плашек «Профессия» и «Хобби» отображается пульсирующий индикатор `ℹ️`, открывающий Bottom Sheet (на смартфонах) или модальное окно (на ПК) с описанием эффекта и кнопкой **«Применить способность»**.

3. **Полный жизненный цикл игры:**
   - **Лобби:** генерация уникального 3-значного кода комнаты (`7A2`, `X9B`), настройка параметров бункера и кнопка **«Загрузить из пака»**, возможность добавить ИИ-ботов для теста.
   - **Раунды вскрытия и обсуждения:** синхронизированный таймер (60/90/120 сек), очередь хода, общая сводка стола.
   - **Голосование и Трибунал:** тайное голосование, учёт щитов/двойных голосов, автоматическая фаза **оправдательных речей (30 сек)** при равенстве голосов и повторное голосование между лидерами антирейтинга.
   - **Финал от ИИ (Gemini API):** расчёт вероятности выживания колонии (0–100%), разбор кризисов внутри убежища, судьба изгнанных и художественный эпилог по главам с анимацией печати текста.

## Быстрый старт и сборка

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка статики для GitHub Pages (в папку /dist)
npm run build
```

## Деплой на GitHub Pages

В проект уже добавлен workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) и относительный базовый путь `base: './'` в [`vite.config.ts`](vite.config.ts):
1. Загрузите репозиторий на GitHub.
2. В разделе **Settings → Pages** выберите **Source: GitHub Actions** (или задеплойте содержимое папки `/dist`).
3. Откройте опубликованный сайт, нажмите **«Админ / Настройки»** и вставьте ваш конфиг Firebase и ключ Gemini API — они сохранятся в `localStorage` вашего браузера, не попадая в публичный код репозитория.
