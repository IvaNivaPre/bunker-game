# БУНКЕР ОНЛАЙН — Веб-приложение настольной психологической игры

Полностью статическое адаптивное веб-приложение (Single Page Application) на **React + TypeScript + Vite + Tailwind CSS**, готовое к деплою на **GitHub Pages**, с синхронизацией в реальном времени через **Firebase** (Realtime Database или Cloud Firestore + локальный мульти-вкладочный режим из коробки).

---

## Возможности

1. **Закрытая страница администрирования (`/admin`):**
   - Защита мастер-паролем (задаётся при первом входе).
   - **Разделение сущностей в редакторе:** изолированная настройка **пресетов бункера**, **сценариев катастроф** и **паков характеристик** (11 категорий со спец. способностями для *Профессии*, *Хобби* и *Спец. возможности*).
   - **Поиск, фильтрация и сортировка:** поиск по названию/описанию/ключевым словам, фильтрация по типу сущности и тегам, сортировка по дате, алфавиту или количеству карт.
   - **Безопасное удаление:** удаление любых паков и пресетов через модальное окно подтверждения (из базы данных и `localStorage`).
   - **Управление активными играми и автоочистка:** просмотр текущих комнат, принудительное завершение и удаление сессий, автоматическое удаление комнат после завершения игры и при неактивности более 24 часов.
   - **Конфигуратор Firebase «на лету»:** сохранение конфига в `localStorage` браузера и проверка соединения.

2. **Мульти-выбор паков характеристик при создании игры:**
   - Хост может выбрать **несколько паков характеристик** с помощью встроенного поиска, фильтрации по тегам и сортировки.
   - Выбранные паки отображаются через запятую, а их карты объединяются в единый пул при раздаче.

3. **Игровой процесс и уведомления:**
   - Корректное подключение по 3-значному коду (`toUpperCase()`, очистка от пробелов, безопасная проверка `rooms/${roomCode}` без ложных сбоев 404).
   - **Модальное оповещение после голосования:** всплывающее окно для всех игроков с именем изгнанного участника, полной сводкой голосов и кнопкой **«ОК»** для перевода изгнанного в статус наблюдателя (`isAlive: false`).
   - **Стандартный финал игры:** поздравительный экран герметизации бункера со списком выживших, их характеристиками, параметрами убежища и автоматическим удалением комнаты из Firebase после завершения.

## Быстрый старт и сборка

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка статики для GitHub Pages (в папку /dist)
npm run build
```
